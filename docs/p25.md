# P25 on the LR2021

[Guides](README.md) / P25

**Software turns the LR2021's raw signal access into P25 Phase 1 voice reception and short P25 transmissions.** This is the same radio chip used for LoRa, with the P25 processing supplied by software.

## First, hear a call

LakeShark received a live P25 call at 154.7850 MHz and played the decoded voice. The LR2021 supplied the samples to LakeShark's decoder. [Live reception results](live-streaming.md).

## Then, record the signal

A one-second recording held 125,000 complex samples. Replaying it through the decoder recovered 27 voice frames with none muted. This provides a repeatable recording for testing improvements to the receiver. [Recording and replay](voice-capture.md).

## Now, send a test tone

Software generated a P25 waveform and uploaded it to the LR2021. A HackRF independently recorded the transmission. The decoder recovered the expected network identifier, talkgroup, source ID, and all 72 voice frames across two runs. Playing those frames reconstructed a 1,011 Hz tone.

**[Listen to the recovered audio](../research/tx-p25/evidence/v13-p25-voice19200/recovered.wav)**

The example sends a short, pre-generated tone burst. The [experiment report](../research/tx-p25/README.md) includes the generator, receiver recordings, decoding results, and reproduction steps.

## What this gives LakeShark

The receive path already makes the onboard radio useful for listening. Recording lets developers replay the same call when improving a decoder. The transmit path adds a way to create repeatable P25 signals for receiver and decoder experiments, with the waveform defined in software.
